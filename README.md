|---|---|---|
| **Windows 10/11** | `RecRoll-Windows-Universal-Installer.exe` | Universal installer for Intel/AMD and ARM64 systems |
| **macOS 11+** | `RecRoll-macOS-Universal.dmg` | Universal disk image for Apple Silicon and Intel |
